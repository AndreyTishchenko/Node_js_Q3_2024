# WebSocket Battleship

Multiplayer Battleship game built with Node.js and WebSocket communication.

The project allows players to create game sessions, connect in real time, and play Battleship through WebSocket-based client-server interaction.

## Features

- Real-time multiplayer gameplay
- WebSocket communication
- Game room creation
- Turn-based battles
- Ship placement system
- Attack and hit detection
- Game state synchronization
- Win/lose logic

## Tech Stack

- Node.js
- JavaScript
- WebSocket

## Installation

```bash
npm install
```

## Run Project

```bash
npm start
```

## Project Structure

- WebSocket server
- Game logic
- Player session handling
- Real-time event communication

## Gameplay

Players:
- connect to the server
- create or join a room
- place ships on the board
- attack opponent coordinates
- receive real-time game updates
